## 1. 분석 목적

드라마 방영이 촬영지 관광에 미치는 효과를 **시간 축** 위에서 정량화한다.

- **언제부터** 효과가 발생하는가? (발현 시점, onset)
- **얼마나 강하게** 나타나는가? (피크 배율, peak index)
- **종영 후 얼마나** 효과가 지속되는가? (지속 기간, duration)

기존 EDA/모델링이 `방영 전후 YoY 성장률`이라는 단일 숫자로 효과를 요약했다면, 본 분석은 방영 기간 전·중·후 전체 시계열을 추적하여 **효과의 동태적 패턴**을 파악한다.

## 3. 분석 방법론

### 3-1. 분석 창 (Analysis Window)

```
분석 시작: 방영 시작일 − 8주
분석 종료: 종영일 + 12주  (단, 데이터 종료일 초과 시 데이터 종료일로 제한)
```

방영 전 8주: 계절적 기저 수준과 사전 화제성 효과 파악  
종영 후 12주: 효과 소멸 시점 파악

### 3-2. 7일 이동평균 (Rolling Average)

일별 방문객·소비 데이터는 요일 효과(주말 급등, 평일 급감)가 강하므로 **7일 중앙 이동평균**으로 스무딩한다.

```python
rolling = series.rolling(window=7, center=True, min_periods=3).mean()
```

### 3-3. Pre-broadcast Baseline (기준선)

방영 시작 **2주 전 ~ 8주 전** 구간(총 6주)의 이동평균 값의 **평균**을 기준선(baseline)으로 정의한다.

```
기준선 구간: [방영시작일 − 8주, 방영시작일 − 2주]
baseline = mean(daily_rolling[기준선 구간])
```

방영 직전 1주를 제외하는 이유: 예고편·사전 홍보로 인한 조기 반응이 기준선에 포함되지 않도록 하기 위함.

### 3-4. 정규화 지수 (Normalized Index)

```
normalized_index(t) = daily_rolling(t) / baseline
```

- `1.0` = 기준선과 동일한 수준
- `1.05` = 기준선 대비 5% 증가
- `0.95` = 기준선 대비 5% 감소

이 지수는 지역·규모 차이를 제거하여 **10개 관광지를 동일한 척도에서 비교**할 수 있게 한다.

### 3-5. 주(週)별 지수 집계

발현 시점 판단은 일별 노이즈를 줄이기 위해 **7일 단위 주별 평균 지수**를 사용한다.

```
week 0 = 방영 시작일부터 +7일 (방영 첫 주)
week -1 = 방영 시작일 -7일 ~ -1일 (방영 전 마지막 주)
week +N = 방영 시작일 +7*N일부터 +7*(N+1)-1일
```

### 3-6. 효과 발현 시점 (Onset) 산정

**정의**: 정규화 지수가 임계값 이상으로 2주 이상 연속 유지되는 **첫 번째 주**

```
탐색 시작: week -4 (방영 4주 전부터 — 사전 홍보·티저 효과 포착)
임계값: 1.05 (기준선 대비 5% 이상)
조건: 2주 이상 연속으로 임계값 초과
onset_days = onset_week × 7  (방영 시작일 기준 일수)
```

| onset_days 해석 | 의미 |
|----------------|------|
| 음수 (예: −14일) | 방영 **전**에 효과 발현 — 예고편·사전 화제성 효과 |
| 0 ~ 방영기간 | 방영 **중** 효과 발현 |
| 방영기간 초과 | 방영이 끝난 **후** 효과 발현 (이례적) |
| 미발현 | 분석 창 내에서 임계값 미도달 |

### 3-7. 종영 후 지속 기간 (Duration After End) 산정

**정의**: 종영 후 임계값 이상을 유지한 **연속 주 수**

```
종영 주차 = ceil((종영일 - 방영시작일).days / 7)
duration_after_end = 종영 주차 이후 weekly_index >= 1.05 인 연속 주 수
```

첫 주에 임계값 미달이면 즉시 0으로 종료 (비연속 회복은 미포함).

### 3-8. 시청률 회차별 날짜 배분

0_ndays 데이터의 회차별 시청률을 **방영 시작일~종영일 구간에 균등 배분**하여 날짜를 부여한다.

```python
ep_dates = pd.date_range(start=broadcast_start, end=broadcast_end, periods=n_episodes)
```

실제 방영 요일(월화/수목/토일)의 정확한 날짜보다 주간 단위 트렌드 분석이 목적이므로 균등 배분으로 충분하다.

### 5-2. 드라마별 특이사항

**충주호 / 눈물의 여왕**
- 소비가 방영 2주 전부터 상승 → 충주 지역이 드라마 화제성에 가장 빠르게 반응
- 소비 피크 1.60배(기준선 대비 +60%)로 10개 중 2위
- 종영 후 7주 지속으로 방문객·소비 모두 최장 지속

**황리단길 / 찬란한 너의 계절에**
- 방문객·소비 모두 방영 1주 전 사전 발현
- 소비 피크 1.71배로 **전체 1위**
- 방문객·소비 모두 종영 후 5주 지속으로 충주호와 함께 최상위
- 경주 지역 관광 인프라(인근 관광지 다수)와 시너지 효과 추정

**인천국제공항 / 킹더랜드**
- 방문객·소비 모두 방영 35일(5주) 후에야 발현 → 효과 발현이 가장 느림
- 하지만 방문객 피크 1.31배로 전체 3위
- 공항의 특성상 단기 트래픽이 변동 요인이 많아 초기 신호 노이즈 가능성

**경복궁 / 혼례대첩**
- 방문객은 방영 14일 전 사전 발현 (예고편·사전 촬영 공개 화제 추정)
- 소비는 방영 42일 후 발현으로 방문객 대비 극단적으로 늦음
- 경복궁이 기존 관광지라 방문 증가가 먼저지만, 소비 환경이 즉각 반응하지 못한 것으로 해석

**세종문화회관 / 우리영화 · 수원시장·행리단길 / 선재 업고 튀어**
- 3개 지역 모두 임계값(+5%) 미도달로 효과 미발현
- 피크 지수도 1.03~1.07배로 매우 낮음
- 원인 추정: 해당 시군구 전체 관광 수요에 비해 드라마 촬영지 규모가 작거나, 지역 내 경쟁 이벤트 존재 가능성

## 7. 주요 발견 및 해석

### 발견 1: 소비가 방문객보다 약 11일 빠르게 발현된다

```
방문객 평균 발현: +19일 (방영 3주차)
관광소비 평균 발현: +8일 (방영 2주차)
```

드라마 방영 초반에는 **기존 방문객의 소비 패턴이 먼저 변화**하고(기존 방문객이 드라마 관련 장소로 이동하거나 관련 소비 증가), 이후 드라마를 보고 새롭게 유입되는 **신규 방문객이 뒤따르는** 순서를 시사한다.

### 발견 2: 사전 발현(방영 전) 패턴이 존재한다

충주호(−14일), 황리단길(−7일), 경복궁(−14일), 송도해수욕장(−7일, 소비)에서 방영 전 효과가 나타났다. 이는 드라마 **예고편 공개 또는 SNS 화제**로 인한 선행 관광 수요로 해석할 수 있다.

### 발견 3: 종영 후 효과는 대부분 단기(1~2주)에 소멸한다

```
전체 평균 종영 후 지속: 방문객 1.4주, 소비 1.5주
최장 지속: 충주호·황리단길 각 7주, 5주
```

대부분의 관광지에서 드라마 효과는 **방영 기간 종료와 함께 빠르게 소멸**한다. 충주호(7주)와 황리단길(5주)은 예외적으로 긴 지속성을 보이는데, 두 지역 모두 기존 관광 인프라가 탄탄하고 SNS 확산이 활발한 관광지 특성을 공유한다.

### 발견 4: 효과 크기(peak index)는 소비가 방문객보다 크다

```
방문객 평균 피크: +13% (1.13배)
관광소비 평균 피크: +25% (1.25배)
```

방문객 수 증가율보다 소비 증가율이 2배 가까이 크다. 드라마 촬영지를 목적지로 삼은 방문객은 **일반 방문객보다 더 많은 소비를 하는 경향**이 있음을 시사한다(팬덤 소비, 굿즈 구매, 맛집 탐방 등).

### 발견 5: 효과 미발현 패턴의 공통점

미발현 3개 지역(세종문화회관, 수원시장, 행리단길)의 공통점:
- 세종문화회관: 대형 공공 문화시설로 자체 유동인구가 커서 드라마 효과가 희석
- 수원시장·행리단길: 동일 드라마(선재 업고 튀어)의 수원 촬영 효과가 수원시 팔달구 **전체** 통계에 묻힘 (시군구 단위 통계의 한계)
