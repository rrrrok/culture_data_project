## 분석 섹션 요약

### 1. 기본 정보
- 10개 관광지-드라마 쌍 목록 출력
- 메타(15) / X 특성 / Y 목표변수(2) / Y 보조정보(8) 컬럼 분류

### 2. Y 변수 분포
- `Y_visit_growth_8w`: 방송 전후 8주 방문객 성장률
- `Y_consume_growth_8w`: 방송 전후 8주 관광소비 성장률

### 3. 결측값 분석
- 결측 있는 특성 목록 및 수량 시각화
- 분산=0 (무의미) 특성 탐지

### 4. X 특성 분포
- 수치형 특성 기술통계 및 변동계수(CV) 확인
- 정적 인프라 특성 / 동적 성장률 특성 분포 시각화

### 5. X-Y 상관관계
- 각 X 특성과 Y의 Pearson 상관계수 계산
- 두 Y 기준 각 상위 15개 특성 시각화 → **모델링 특성 선별 기준**

### 6. X-X 상관관계
- 유망 특성 간 히트맵으로 다중공선성 파악
- `|r| ≥ 0.85` 중복 특성 쌍 목록 출력

### 7. 산점도
- 주요 특성 vs 방문객/소비 성장률 개별 산점도 (관광지명 레이블 포함)

### 8. 종합 요약
- 후보 특성 목록 (`|r| ≥ 0.30`) 출력
- 모델링 전략 권고

| 행리단길 | -4.9% | -4.2% |

- 두 Y 상관계수: **r = 0.645** — 연동되지만 별개의 지표
- 방문객과 소비가 모두 증가한 곳: 충주호·황리단길·인천국제공항 3곳

### 결측값
- 네이버 검색 관련 특성 전체: 10개 중 **1개 결측** (10%)
- `naver_검색지수_growth_8w`, `네이버_연관검색지수_growth_8w`, `최근접공영주차장거리_m`: **2개 결측** (20%)
- 대응 방안: 결측 1~2개는 중앙값 대체 또는 해당 특성 제외

### X-Y 상관관계 (유망 특성)

| 특성 | r(visit) | r(consume) | 해석 |
|------|----------|------------|------|
| `ic_입구통행량_growth_8w` | **+0.65** | **+0.75** | 고속도로 유입 증가 → 방문·소비 모두 증가 |
| `ic_총통행량_growth_8w` | **+0.63** | **+0.65** | 동일 맥락 |
| `ic_통행량_growth_8w` | **+0.63** | **+0.65** | 동일 맥락 |
| `최근접철도지하철역거리_km` | +0.52 | **+0.95** | 대중교통 불편 → 자가용 방문 → 소비 더 큼 |
| `최근접공항거리_km` | — | **+0.65** | 도심 외 관광지 효과 |
| `인근_문화/액티비티수` | **+0.57** | — | 주변 즐길거리 많을수록 방문 증가 |
| `네이버_관광지지수_log_growth_8w` | **+0.55** | — | 검색 증가 → 방문 연결 |
| `인근_자연명소수` | +0.40 | +0.55 | |

### 인사이트 요약

1. **IC 통행량 성장률**이 두 Y 모두에서 가장 강한 예측 특성 → 자가용 접근성이 핵심
2. **철도역 거리** r=0.95 for consume → 대중교통이 불편한 외곽 관광지(충주호·황리단길)에서 소비가 압도적으로 더 큼. 자가용 여행 특성상 지출이 많은 패턴
3. **네이버 검색 성장**은 방문에는 유효(r=0.55)하나 소비에는 약함 → 검색에서 방문까지는 연결되지만, 소비 결정은 다른 요인(인프라·접근성)에 의존
