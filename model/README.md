## 1. 분석 목적

드라마 촬영지가 해당 지역 관광에 미치는 긍정적 효과를 결정하는 **요인(Feature)**을 정량적으로 파악하고 중요도 순위를 도출한다.

- **종속변수(Y)**: 방문객 YoY 성장률, 관광소비 YoY 성장률
- **독립변수(X)**: 드라마 특성(시청률, 플랫폼) + 지역 인프라(교통·주차·주변 관광지) + 온라인 반응(네이버 검색 지수)
- **핵심 방법론**: XGBoost / RandomForest + **SHAP** 기반 요인 중요도

> 샘플이 10개(n=10)로 소규모이므로 예측 정확도 자체보다 **요인 중요도 해석**에 분석의 초점을 둔다.

## 3. 특성 선택 및 전처리

### 3-1. 중복 제거 원칙

EDA에서 확인된 고상관(|r| ≥ 0.85) 특성 쌍을 제거해 다중공선성을 줄였다.

| 그룹 | 원본 컬럼 | 제거 | 유지 | 근거 |
|------|-----------|------|------|------|
| IC 통행량 | before / **during** / after | before, after | **during** | 세 컬럼 간 r > 0.99, 방송 기간 중 수치가 분석에 가장 직접적 |
| 네이버 관광지 지수 | before / during / **after4w** / growth | before, during | **after4w, growth** | before↔during r=0.971, after4w가 Y와 상관 최고 |
| 네이버 드라마 지수 | before / **during** / after / growth | before, after | **during, growth** | after↔growth r=0.929, during이 Y_visit와 상관 높음 |

n=10의 소규모에서 삭제 시 정보 손실이 더 크므로 평균 대체 선택.

## 4. 모델 구성

### XGBoost

```python
XGBRegressor(
    n_estimators    = 100,    # 트리 개수
    max_depth       = 2,      # 최대 깊이 (n=10 과적합 방지를 위해 얕게 설정)
    learning_rate   = 0.1,    # 학습률
    subsample       = 0.8,    # 행 샘플링 비율
    colsample_bytree= 0.8,    # 특성 샘플링 비율
    random_state    = 42,
)
```

- **max_depth=2**: 샘플이 10개로 매우 적어 깊은 트리는 즉시 과적합됨. 최대 4개 리프 노드까지만 분기 허용.
- **subsample / colsample_bytree**: 각 트리 학습 시 데이터와 특성을 80%씩 무작위 샘플링해 다양성 확보.

### RandomForest

```python
RandomForestRegressor(
    n_estimators    = 500,    # 트리 개수 (많을수록 분산 감소)
    max_depth       = 3,      # 최대 깊이
    min_samples_leaf= 1,      # 리프 최소 샘플 수
    random_state    = 42,
    n_jobs          = -1,     # 병렬 처리 (모든 CPU 코어 사용)
)
```

- **n_estimators=500**: 500개 트리의 앙상블 평균으로 분산을 낮춤.
- **max_depth=3**: XGBoost보다 한 단계 깊게 허용. RF는 배깅(Bagging) 구조라 개별 트리의 과적합이 앙상블에서 희석됨.

## 5. 검증 방법 — LOO-CV

### LOO-CV(Leave-One-Out Cross Validation)란?

n=10에서 일반적인 k-fold(k=5, k=10)는 테스트셋이 1~2개로 너무 적어 통계적으로 불안정하다.  
**LOO-CV**는 한 번에 1개 샘플을 테스트셋으로 빼고, 나머지 9개로 학습하는 과정을 10회 반복한다.

```
반복 1: [2~10번] → 학습, [1번] → 예측
반복 2: [1,3~10번] → 학습, [2번] → 예측
...
반복 10: [1~9번] → 학습, [10번] → 예측
→ 10개 예측값을 모아 실제값과 비교
```

- 샘플 10개를 모두 1번씩 테스트에 사용하므로 **데이터 낭비 없음**
- n이 작을수록 LOO-CV가 사실상 유일한 신뢰할 수 있는 검증 방법

### 성능 지표 정의

| 지표 | 공식 | 해석 |
|------|------|------|
| **MAE** (Mean Absolute Error) | `mean(|y_true − y_pred|)` | 예측 오차의 평균 절댓값. Y와 같은 단위(성장률). 작을수록 좋음. |
| **R²** (결정계수) | `1 − SS_res / SS_tot` | 모델이 Y 분산을 설명하는 비율. 1=완벽, 0=평균 예측 수준, **음수=평균보다 나쁨** |

## 6. LOO-CV 성능 결과

| 모델 | 타겟 | MAE | R² |
|------|------|-----|----|
| XGBoost | 방문객 YoY 성장률 | 0.1443 | −1.7816 |
| RandomForest | 방문객 YoY 성장률 | **0.1323** | **−1.0915** |
| XGBoost | 관광소비 YoY 성장률 | 0.1043 | −0.8796 |
| RandomForest | 관광소비 YoY 성장률 | **0.1005** | **−0.6895** |

### 수치 해석

**MAE 해석 (Y의 범위 대비 오차)**

| Y 변수 | 실제 범위 | 평균값 | RF MAE | 오차 비율 |
|--------|-----------|--------|--------|-----------|
| 방문객 YoY | 0.017 ~ 0.428 | ~0.095 | 0.1323 | 약 ±13.2%p |
| 소비 YoY | −0.013 ~ 0.255 | ~0.068 | 0.1005 | 약 ±10.1%p |

- 방문객의 경우 인천국제공항(0.428)처럼 이상치(outlier)에 해당하는 값이 포함되어 MAE가 상대적으로 크게 나타남.
- 소비 성장률은 변동 범위가 좁아 MAE가 상대적으로 작음.

**R² 음수 해석**

R²가 음수라는 것은 모델의 예측이 **단순히 "전체 평균값을 항상 예측"하는 것보다도 나쁨**을 의미한다.

```
R² < 0  →  모델 예측 오차 > 전체 평균으로 예측했을 때의 오차
```

이는 n=10의 극단적인 소규모에서 LOO-CV 시 **학습 데이터 9개**로 일반화하는 것 자체의 한계에서 비롯된다.  
중요한 것은, **R²가 낮아도 SHAP 기반 요인 중요도는 유효하다**.  
SHAP은 모델이 학습한 패턴(특성과 Y의 관계)을 분해하는 것이지, 예측 성능과 직결되지 않는다.

> **결론**: 이 분석에서 LOO-CV 성능은 참고 지표이며, 핵심 결과는 SHAP 기반 요인 중요도 순위다.  
> RF가 두 타겟 모두에서 MAE와 R² 모두 XGBoost보다 소폭 우세.

## 7. Feature Importance (내장 지표)

### 산정 방법

| 모델 | 내장 Importance 기준 | 의미 |
|------|---------------------|------|
| XGBoost | `gain` (기본값) | 해당 특성으로 분기할 때 손실(MSE)이 평균적으로 얼마나 감소하는가 |
| RandomForest | `mean decrease in impurity` | 해당 특성으로 분기 시 불순도(MSE) 감소의 전체 평균 |

### 한계

- 내장 Importance는 **방향성(양/음 영향)**을 알 수 없음
- 연속형 변수나 고유값이 많은 특성에 유리하게 편향될 수 있음
- **SHAP이 이 한계를 보완한다**

## 8. SHAP 분석

### SHAP(SHapley Additive exPlanations)이란?

게임 이론의 **샤플리 값(Shapley Value)**을 머신러닝에 적용한 방법으로, 각 특성이 개별 예측값에 얼마나 기여했는지를 분해한다.

```
예측값 = 기준값(base value) + SHAP(특성1) + SHAP(특성2) + ... + SHAP(특성13)
```

- 기준값: 모든 샘플의 Y 평균값 (모델이 아무 정보 없이 예측할 때의 값)
- 각 특성의 SHAP 값: 해당 특성이 기준값 대비 예측값을 얼마나 밀어올리거나(양) 내렸는지(음)

### SHAP 시각화 종류

#### Beeswarm Plot (`shap_beeswarm_*.png`)

```
특성 중요도 순으로 정렬 (Y축)
X축: SHAP 값 (양수 → Y 증가 기여, 음수 → Y 감소 기여)
점 색깔: 해당 특성의 실제값 (빨강 = 높음, 파랑 = 낮음)
```

- **방향성과 크기를 동시에** 파악 가능
- 예: `최근접IC거리_km`의 SHAP이 음수, 점 색이 빨강(거리 멀) → IC가 멀수록 소비 Y 감소

#### Bar Plot (`shap_bar_*.png`)

```
X축: mean |SHAP| (각 샘플의 |SHAP| 값 평균)
특성 중요도 순위를 크기로만 표현 (방향성 없음)
```

- 어떤 특성이 전체적으로 예측에 얼마나 중요한지 한눈에 파악

#### 비교 차트 (`shap_comparison.png`)

XGBoost와 RandomForest의 `mean |SHAP|`을 나란히 비교.  
두 모델에서 일관되게 높은 특성이 **신뢰할 수 있는 핵심 요인**이다.

### SHAP 요인 순위 산정 방법

```
mean |SHAP| (XGBoost) + mean |SHAP| (RandomForest)
───────────────────────────────────────────────────  = 최종 중요도 점수
                      2
```

두 모델 평균으로 단일 모델의 편향을 완화하고 안정적인 순위를 도출.

## 10. 종합 해석 및 시사점

### 방문객 vs 소비의 핵심 요인 비교

| 요인 범주 | 방문객 성장 기여 | 소비 성장 기여 |
|-----------|----------------|----------------|
| 콘텐츠 화제성 (시청률·검색량) | ★★★ **1~4위 독점** | ★★ 5위 수준 |
| 교통 접근성 (IC 거리) | ★★ 5위 | ★★★ **1위** |
| 주변 관광자원 (인근 관광지) | ★ 10위 | ★★★ **2위** |
| 주차 인프라 (공영주차장) | ★ 11위 | ★★ 4위 |
| 플랫폼 (넷플릭스) | ★ 13위 | ★ 11위 |

### 주요 발견

1. **"보는 것"과 "소비하는 것"을 결정하는 요인이 다르다**
   - 방문객 유입: 드라마를 보고 싶어서 옴 → **콘텐츠 자체의 힘**이 결정
   - 관광소비 증가: 방문 후 얼마나 쓰는지는 **현지 인프라**가 결정

2. **시청률과 네이버 관광지 검색량은 방문객 예측의 핵심 선행지표**
   - 특히 `네이버_관광지지수_after4w_mean`(방송 후 4주 검색량)이 두 Y 모두에서 상위권
   - 드라마 종영 후에도 관광지 검색이 유지되는 관광지일수록 효과가 큼

3. **IC 접근성은 소비의 게이트키퍼**
   - 자동차로 쉽게 올 수 있는 곳(IC 가까움)일수록 실제 관광 소비가 증가
   - 대중교통(철도·지하철) 접근성도 소비에서 7위로 방문(12위)보다 중요하게 나타남

4. **넷플릭스 플랫폼 효과는 생각보다 낮음**
   - 두 Y 모두에서 최하위권(11~13위)
   - 국내 시청률이 실제 국내 관광에 미치는 영향이 글로벌 플랫폼 노출보다 더 직접적임을 시사

5. **두 모델 간 일관성**
   - 1~3위 특성은 XGBoost와 RandomForest 모두 유사하게 평가 → **신뢰도 높음**
   - 하위권 특성(11~13위)은 모델 간 편차가 크므로 해석 주의 필요

### 정책·실무적 시사점

- 촬영지 선정 시 시청률이 높거나 화제성이 기대되는 드라마와의 협력이 방문객 유입에 효과적
- 소비 증대를 목표로 한다면 IC 인근 접근로 개선, 공영주차장 확충, 주변 관광자원 연계가 핵심
- 드라마 방영 후 4주간 관광지 검색량 모니터링으로 관광 효과를 조기 예측 가능
